# Expense Tracker - NestJS Back-end

A robust financial management API built with NestJS, MySQL, and Sequelize.

## 🌟 Key Features
- **User Authentication**: Secure JWT-based login and registration.
- **Income Tracking**: Manage multiple income sources.
- **Expense Categorization**: Group expenses into custom categories.
- **Reminders**: Set up payment reminders.
- **Reports**: Detailed monthly financial reports with daily breakdowns.

## 🚀 Quick Setup

1. **Install Dependencies**:
   ```bash
   $ npm install
   ```

2. **Configure Environment**:
   Create a `.env` file based on the keys listed in the technical documentation.

3. **Run the Project**:
   ```bash
   # Development mode
   $ npm run start:dev
   ```
